# 90 Days

本目录用于管理一个有明确起止时间的 AI Agent Engineering 学习周期。它关注节奏、输出和复盘，不承载长期知识正文或产品源码。

## 结构

- [`ROADMAP.md`](ROADMAP.md)：阶段目标、核心主题与阶段产物。
- [`daily/`](daily/)：每日学习/开发日志，文件名为 `YYYY-MM-DD.md`。
- [`reviews/`](reviews/)：每周与阶段复盘，文件名建议为 `week-NN.md` 或 `phase-N.md`。

## 使用原则

1. 每周先定义一个可验证输出，而不是只列阅读材料。
2. 每日记录目标、实际动作、证据、问题和下一步；短而真实即可。
3. 每周将稳定理解提炼到 `knowledge/`，将待验证问题转成 `playground/` 实验。
4. 每个阶段至少产生一个可运行产物或可比较评测。
5. 计划可根据证据调整；调整时记录原因，不为了完成打卡而保留失效任务。

## 启动一个周期

- 在 [`ROADMAP.md`](ROADMAP.md) 填写开始/结束日期、每周投入和目标项目。
- 复制 [`../templates/daily-log.md`](../templates/daily-log.md) 创建第一篇日志。
- 在第一周复盘时校准路线的难度和范围。
