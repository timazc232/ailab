# Knowledge

本目录保存经过提炼、预期长期有效的 AI Agent Engineering 知识。它不是书签堆、课程流水账，也不是模型回答的原样存档。

## 一篇合格知识笔记

- 聚焦一个问题或概念，标题可以直接表达主题。
- 区分事实、经验性结论、个人推断和开放问题。
- 给出来源、验证方式、适用条件和已知反例/限制。
- 能链接到相关实验或项目证据。
- 新增后登记到 [`INDEX.md`](INDEX.md)。

## 命名与组织

- 文件名使用 `kebab-case.md`。
- 当某一主题出现至少数篇真实笔记时，再创建对应子目录，避免预先制造空分类。
- 相同概念优先更新已有笔记；观点发生变化时保留变更原因和日期。

使用 [`../templates/knowledge-note.md`](../templates/knowledge-note.md) 开始一篇新笔记。
