## 学到的内容

### 已验证

- ufw 默认 DROP 不影响 loopback 服务；绑定 127.0.0.1 的服务外部不可达，无需开端口。
- HTTP 层失败（4xx/5xx）与 payload 层失败（200+非法 JSON）是可分离的信号。
- R1–R5 顺序分类对 7 场景判定全部正确且可重复（3 次运行零漂移）。
- s6 为读阶段超时（`phase=response-status TimeoutError`）：请求已完整发出、响应未到达——印证 transport failure ≠ 服务端未处理。
- s7 与 s1 在 HTTP 层完全同构（200 + 合法 JSON），唯一区分信号是 `finish_reason`：HTTP success != model task success 获得实证。
